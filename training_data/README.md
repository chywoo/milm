# 📚 MiniLLM Pre-training Datasets Guide

This directory (`training_data/`) contains a curated collection of high-quality text corpora designed for effective pre-training of **MiniLLM (Lightweight Transformer Decoder-Only Language Model)**. Depending on model capacity and target capabilities (literary prose, children's stories/reasoning, encyclopedic knowledge, narrative fiction), you can select individual datasets or combine them for pre-training.

---

## 📊 Dataset Overview

| Dataset | Source | File Size | Line Count | Characters | Recommended Use Case |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`tinyshakespeare.txt`** | Andrej Karpathy (char-rnn / nanoGPT) | 1.1 MB | 40,000 | ~1.11M | Fast prototyping, dialogue/verse generation |
| **`tinystories_sample.txt`** | Microsoft Research (Ronen Eldan & Yuanzhi Li) | 5.0 MB | 37,063 | ~5.24M | **Small LLM reasoning/grammar learning (Top Pick)** |

| **`sherlock_holmes.txt`** | Project Gutenberg (Arthur Conan Doyle) | 593 KB | 12,306 | ~581K | Narrative continuity, detective prose, long-form dialogue |
| **`alice_in_wonderland.txt`** | Project Gutenberg (Lewis Carroll) | 148 KB | 3,384 | ~145K | Micro-model testing, fantasy literary style |

## 🔍 Dataset Details and Sources

### 1. Tiny Shakespeare (`tinyshakespeare.txt`)
* **Source**: [Andrej Karpathy char-rnn GitHub Repository](https://github.com/karpathy/char-rnn)
* **Download URL**: `https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt`
* **License**: Public Domain / Open Source
* **Overview**: Excerpts and dialogues from classic Shakespearean plays. Widely used as a standard benchmark in Karpathy's `nanoGPT` and `minGPT`.
* **Training Characteristics**:
  * Clear character dialogues (`First Citizen:`, `MENENIUS:`) and monologue structures.
  * Compact size (~1.1 MB) converges within minutes on single GPU or Apple Silicon.
  * Produces archaic vocabulary and verse cadences after training.

### 2. TinyStories Sample (`tinystories_sample.txt`) ⭐ (Highly Recommended)
* **Source**: Microsoft Research ([TinyStories: How Small Can Language Models Be and Still Speak Coherent English?](https://arxiv.org/abs/2305.07759))
* **Download URL (HuggingFace)**: `https://huggingface.co/datasets/roneneldan/TinyStories`
* **License**: CDLA-Permissive-2.0
* **Overview**: Synthetic short stories generated by GPT-3.5 and GPT-4 using vocabulary typical of 3 to 4-year-olds. Designed to allow sub-10M parameter models to generate fluent, grammatically correct English with coherent causal reasoning.
* **Training Characteristics**:
  * Simple, clean vocabulary enables fast convergence for small tokenizers and architectures.
  * Highly optimized for context coherence, causality, and commonsense reasoning.
  * Smooth and stable Perplexity (PPL) reduction curve.

### 3. WikiText-2 (`wikitext2_train.txt`)
* **Source**: Salesforce Research ([The WikiText Long Term Dependency Language Modeling Dataset](https://blog.salesforceairesearch.com/the-wikitext-long-term-dependency-language-modeling-dataset/))
* **Download URL**: `https://raw.githubusercontent.com/pytorch/examples/main/word_language_model/data/wikitext-2/train.txt`
* **License**: Creative Commons Attribution-ShareAlike License (CC BY-SA 4.0)
* **Overview**: A collection of over 2 million tokens extracted from the set of verified Good and Featured articles on English Wikipedia.
* **Training Characteristics**:
  * Formal, encyclopedic writing covering academic, historical, and scientific topics.
  * Complex sentence structures with rich proper nouns and specialized vocabulary.
  * Standard benchmark for evaluating language model perplexity.

### 4. Sherlock Holmes & Alice in Wonderland (Project Gutenberg)
* **Source**: [Project Gutenberg](https://www.gutenberg.org/)
  * **Sherlock Holmes**: `https://www.gutenberg.org/files/1661/1661-0.txt` (Arthur Conan Doyle)
  * **Alice in Wonderland**: `https://www.gutenberg.org/files/11/11-0.txt` (Lewis Carroll)
* **License**: Public Domain
* **Overview**: Full text from classic English literature.
* **Training Characteristics**:
  * Rich narrative structure, descriptive imagery, and deductive reasoning dialogues.
  * Ideal for rapid overfitting checks and style transfer experiments on medium/small datasets.

## 🚀 How to Train

### Option 1: Train on the Entire Combined Corpus
Set `data_dir` to `training_data` in `config.yaml` or `src/config.py` to automatically concatenate all `.txt` files in the directory (~17.8 MB) for pre-training.

```yaml
# config.yaml
train:
  data_dir: "training_data"
  epochs: 50
  batch_size: 64
  learning_rate: 0.0005
```

```bash
python scripts/train.py
```

---

### Option 2: Train on a Specific Dataset
To focus training on a single corpus (e.g., `tinystories_sample.txt` or `tinyshakespeare.txt`), copy the file to a dedicated data directory (e.g., `data/`).

```bash
# 1. Train on TinyStories
mkdir -p data
cp training_data/tinystories_sample.txt data/

# 2. Or train on Tiny Shakespeare
# cp training_data/tinyshakespeare.txt data/

# 3. Launch training (uses default data_dir="data")
python scripts/train.py
```
